# Portfólio Web - Laís Melo

Landing page profissional e responsiva desenvolvida na disciplina de Front-End e Back-End para Web.
O site apresenta minha formação, habilidades técnicas, projetos e um formulário de contato, além de uma página com o meu currículo.

## Tecnologias utilizadas

- **HTML5**: estrutura das páginas
- **CSS3**: estilização e personalização do tema (azul marinho)
- **Bootstrap 5**: navbar, grid system, cards, formulário e responsividade
- **JavaScript**: atualização automática do ano no rodapé
- **Git e GitHub**: versionamento e hospedagem do código

## Estrutura do projeto

```
portfolio-web/
├── index.html        # Landing page (Navbar, Hero, Sobre, Habilidades, Projetos, Contato e Footer)
├── curriculo.html    # Página do currículo
├── CSS/
│   └── style.css     # Estilos personalizados
├── IMG/
│   └── eu.jpeg       # Foto de perfil
└── JS/
    └── script.js     # Scripts da página
```

## Funcionalidades

- Navbar responsiva com rolagem suave entre as seções
- Hero com apresentação e botão de chamada para ação
- Seção de habilidades usando o Grid do Bootstrap
- Três cards de projetos
- Formulário de contato com Nome, E-mail e Mensagem
- Layout adaptável a celulares, tablets e computadores

## Como executar

1. Baixe ou clone o repositório:
   ```bash
   git clone https://github.com/laismelo123/portfolio-web.git
   ```
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador (é necessário internet para carregar o Bootstrap).
